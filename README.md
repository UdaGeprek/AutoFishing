# 🎣 Albion Online Fishing Bot (PoC)

An advanced, undetectable computer vision-based automation tool for Albion Online, written in Python using OpenCV. 

> **Disclaimer / Дисклеймер:** Данный проект создан исключительно в образовательных целях для изучения алгоритмов компьютерного зрения (Computer Vision), систем низкоуровневой эмуляции ввода (Ring 3 OS Input) и методов обхода систем защиты (EAC Device Detection). Разработчики не несут ответственности за использование софта на живых серверах.

---

## 🛠️ Архитектура и технологии (Tech Stack)

Проект спроектирован по модульному принципу без внедрения в память процесса игры (External/Passive Approach), что делает его невидимым для сигнатурного анализа античитов:

*   **Python 3.11+** — основная программная логика.
*   **OpenCV (Open Source Computer Vision Library)** — обработка изображений, цветовая сегментация (HSV), поиск контуров и трекинг объектов.
*   **MSS (Multiple Screen Shots)** — сверхбыстрый захват фреймбуфера экрана напрямую через WinAPI (60+ FPS).
*   **Interception / WinAPI cTypes** — низкоуровневая эмуляция аппаратного ввода мыши для обхода поведенческих блокировок.
